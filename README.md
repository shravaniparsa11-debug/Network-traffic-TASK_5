# Network Traffic Capture using PCAPdroid TASK_5

## Objective
To capture and analyze network traffic generated by applications using PCAPdroid.

## Tool Used
- PCAPdroid
- Android smartphone
- Chrome browser

## Steps Performed
1. Installed and opened PCAPdroid.
2. Configured PCAP file saving.
3. Started traffic capture.
4. Opened a website using Chrome.
5. Captured the generated network traffic.
6. Checked the Connections section.
7. Verified HTTPS traffic on port 443.
8. Saved the captured traffic as a PCAP file.

## Capture Result
PCAPdroid successfully captured network traffic.

Example:
- Chrome → www.google.com
- Protocol: HTTPS
- Port: 443

## Evidence
Screenshots show:
- PCAPdroid capture running
- PCAP file successfully created
- HTTPS connections captured

## Conclusion
The task was successfully completed. PCAPdroid was used to capture and observe HTTPS network traffic, and the captured traffic was saved in PCAP format.
